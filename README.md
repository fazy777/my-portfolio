# Muhammad Faizan Ali - Portfolio

A professional portfolio website for Muhammad Faizan Ali, a Cyber Security student at UET Lahore and a Java Developer.

## Features

- **Responsive Design:** Built with React, TypeScript, and Tailwind CSS.
- **Cyber Security Focus:** Showcasing security projects and skills.
- **Java Development:** Highlighting expertise in Java OOP, JDBC, and SQL.
- **Contact Form:** Integrated with Supabase for handling messages.
- **Smooth Animations:** Using Lucide icons and Tailwind animations.

## Tech Stack

- **Frontend:** React, TypeScript, Vite
- **Styling:** Tailwind CSS, Lucide React
- **Backend:** Supabase (for contact form)
- **Deployment:** Ready for Vercel/Netlify

## Getting Started

1. Clone the repository.
2. Install dependencies:
   ```bash
   npm install
   ```
3. Set up environment variables in a `.env` file:
   ```env
   VITE_SUPABASE_URL=your_supabase_url
   VITE_SUPABASE_ANON_KEY=your_supabase_anon_key
   ```
4. Run the development server:
   ```bash
   npm run dev
   ```
